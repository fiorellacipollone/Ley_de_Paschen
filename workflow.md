# Workflow 
Información sobre los archivos:
* **datos.xlsx** $\rightarrow$ archivo de excel con los datos experimentales. Se sobreescribe conforme se van ejecutando los códigos completando la información.
* **functions.jl** $\rightarrow$ Módulo con las funciones específicas que se importan sobre los archivos.
* **xlsx_analisis.jl** $\rightarrow$ Módulo para la manipulación y extracción de información del excel.
* **ads.jl** $\rightarrow$ de "adscripción" xd (estaba sin creatividad), por el momento funciona como el main donde se ejecuta todo.
* **graphs_ina_day.jl** $\rightarrow$ compara las mediciones para distintas distancias hechas en un día.
